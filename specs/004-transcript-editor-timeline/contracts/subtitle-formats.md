# Contract: subtitle files

## Export

- **SRT**: UTF-8 with no BOM, cues numbered from 1, `HH:MM:SS,mmm --> HH:MM:SS,mmm`, text on one line, a blank line after each cue. No style.
- **WebVTT**: UTF-8, first line `WEBVTT`, a `STYLE` block with `::cue { ... }` from the caption template, cues `HH:MM:SS.mmm --> HH:MM:SS.mmm line:<n>% position:50% align:center`, text escaped for `&`, `<`, `>`.
- `source = both`: original text, a line break, translated text in one cue.
- Times are the transcript's `startMs` and `endMs`, never `dubStartMs`. Lines with empty text are skipped.

## Import

- Reads SRT (`,` or `.` before milliseconds) and WebVTT (header, notes, `STYLE`, `REGION`, cue ids and settings skipped). BOM and CRLF handled.
- Encoding: BOM, then UTF-8, then a guess; the name used is reported. Unreadable: `SUBTITLE_ENCODING_UNKNOWN`.
- Tags and positioning marks are dropped; a cue's lines are joined with a space.
- Cues are sorted by start time. A cue with end before start is refused with `SUBTITLE_PARSE_FAILED` naming its number. A file with no cue at all is refused.

## Round trip (SC-003)

For any transcript: export translated SRT or VTT, import with `replaceText` into a project of the same lines, and every line has equal text and times within 1 ms (times are written to the millisecond, so equal).
