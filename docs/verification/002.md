## Problems found while checking

- **eSpeak NG is GPL-3.0.** Piper voices need it, and sherpa-onnx links it into its wheel. The sidecar runs as a separate program and the pronunciation data is a separate download with a notice, but whether that is enough for the installer and the runtime pack is a licence question for the owner. See `docs/dependencies.md`.
- **No local engine on Windows on ARM.** `ctranslate2` has no wheel for it, so there is no runtime entry for that platform.
- **No music separation on Intel Macs.** `demucs` needs `sphn`, which has no wheel for them. Those Macs can use fast mode.
- **sherpa-onnx 2.0.1 cannot read text with Piper voices** (no pronunciation frontend), so the lock files pin 1.13.8.
- **Speaker count:** a first version of the test accepted a silent fallback to one speaker. The speaker model was not being found; fixed, and the test now requires two speakers on the fixture.
- **Speaker ids are per section.** `spk1` in one 5-minute section is not guaranteed to be the same person as `spk1` in the next. Gender and voice follow the section, so a speaker may change voice between sections.
- **Translation uses no neighbour context** (T038 asks for it). Lines are translated one by one in batches.
- **Voice coverage is five languages** (English twice, French, German, Spanish) and mostly one gender each. Other languages get no voice yet.
- **macOS FFmpeg** is hosted on the project's own GitHub release (built locally; the Intel build only ran under Rosetta). The Windows FFmpeg links still point at BtbN autobuilds, which get pruned.
