## Problems found while checking

- **eSpeak NG is GPL-3.0.** Piper voices need it, and sherpa-onnx links it into its wheel. The sidecar runs as a separate program and the pronunciation data is a separate download with a notice, but whether that is enough for the installer and the runtime pack is a licence question for the owner. See `docs/dependencies.md`.
- **No local engine on Windows on ARM.** `ctranslate2` has no wheel for it, so there is no runtime entry for that platform.
- **No music separation on Intel Macs.** `demucs` needs `sphn`, which has no wheel for them. Those Macs can use fast mode.
- **sherpa-onnx 2.0.1 cannot read text with Piper voices** (no pronunciation frontend), so the lock files pin 1.13.8.
- **Speaker count:** a first version of the test accepted a silent fallback to one speaker. The speaker model was not being found; fixed, and the test now requires two speakers on the fixture.
- **Speaker ids are per section.** `spk1` in one 5-minute section is not guaranteed to be the same person as `spk1` in the next. Gender and voice follow the section, so a speaker may change voice between sections.
- **Translation uses no neighbour context** (T038 asks for it). Lines are translated one by one in batches.
- **Voices:** Kokoro (15 voices, 8 languages, both genders in most) is preferred over Piper wherever it covers the language. Piper still covers German and a second English voice. Other languages have no voice yet. Kokoro was checked by synthesis in all 8 languages and in a full dub of the French clip; how natural it sounds has not been judged by anyone.
- **macOS FFmpeg** is hosted on the project's own GitHub release (built locally; the Intel build only ran under Rosetta). The Windows FFmpeg archives are mirrored on the project's release too, unchanged from BtbN; none of it has been run on Windows.

## US2 notes

- **Fallbacks are real, not just labels:** subtitles only (skips speech and mixing, exports `.srt`), a generic voice (the best voice of another language), pivot through English (two translation hops) and opt-in to non-commercial models. Only the first three have been run, and only with the fake sidecar. The catalogue has no non-commercial entries yet, so opt-in has no real model behind it.
- **A detected language equal to the target stops the run** with `SAME_LANGUAGE` and asks the user to confirm; resuming continues.
- **Not checked:** the language picker with real, long lists in the real window (the list has about 100 languages).
